# Sharing the portfolio on LinkedIn (free)

## 1. Put the site online with GitHub Pages (free, permanent link)

1. **Merge the site into `main`.** On github.com/chugharchish-blip/portfolio, open a pull request from `claude/risk-audit-portfolio-site-qxfnca` into `main` and click **Merge**.
2. **Make the repository public.** Go to **Settings → General → Danger Zone → Change visibility → Public**. GitHub Pages is free for public repositories. The repository contains no client names.
3. **Turn on Pages.** Go to **Settings → Pages**. Under *Build and deployment*, set *Source* to **Deploy from a branch**, then set *Branch* to **main** with folder **/ (root)**, and click **Save**.
4. After 1–2 minutes the site is live at **https://chugharchish-blip.github.io/portfolio/**. Open it in a private browser window to check it.
5. Paste the link into **https://www.linkedin.com/post-inspector/** so LinkedIn fetches the preview image and title.

## 2. Add it to your LinkedIn profile

- **Featured section** (most visible): on your profile, go to **Add profile section → Recommended → Add featured → Add a link**, paste the URL, and set the title to "Portfolio: Internal Audit, Controls, GRC & Fraud Investigations".
- **Case study PDFs:** under **Add featured → Add media**, upload each PDF from `downloads/`. LinkedIn shows them as swipeable documents.
- **Contact info:** click the pencil on your intro, then **Contact info → Add website**. Paste the URL and set the type to *Portfolio*.
- **About section:** end it with "Case studies and portfolio: https://chugharchish-blip.github.io/portfolio/".
